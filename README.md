# Helios

[![Tests](https://github.com/DiogoAlbq/Helios/actions/workflows/test.yml/badge.svg)](https://github.com/DiogoAlbq/Helios/actions/workflows/test.yml)

Steam launch wrapper for NVIDIA GPUs on Linux, written in Bash.

Detects the GPU tier via `nvidia-smi`, composes Proton/DXVK/VKD3D environment variables using profile algebra, and passes the game command through `exec` without interfering with Steam's `--` arguments.

## Quick install

```bash
TMP_DIR=$(mktemp -d) && curl -fL "https://github.com/DiogoAlbq/Helios/archive/refs/heads/main.tar.gz" -o "$TMP_DIR/helios.tar.gz" && tar -xzf "$TMP_DIR/helios.tar.gz" -C "$TMP_DIR" && (cd "$TMP_DIR/Helios-main" && ./install.sh) && rm -rf "$TMP_DIR"
```

## Installation

### From a local clone

```bash
./install.sh                  # installs to ~/.local/bin
sudo ./install.sh             # installs to /usr/local/bin
./install.sh --prefix ~/bin   # custom prefix
./install.sh --create-aliases # also creates alias symlinks from config
```

`install.sh` copies `bin/helios` into the target bin directory, links `hx -> helios`, and writes a default `~/.config/helios/helios.conf` if none exists. Make sure `~/.local/bin` is on your `PATH`:

```bash
export PATH="$HOME/.local/bin:$PATH"
```

## Steam Launch Options

Right-click a game -> Properties -> General -> Launch Options:

| Launch option | Behavior |
|---|---|
| `helios -- %command%` | Uses symlink alias, AppID override, config default, or `auto` |
| `helios --auto --full -- %command%` | GPU auto-detection plus `full` |
| `helios --auto --no-rt -- %command%` | GPU auto-detection without ray tracing |
| `helios --profile=ultra,-latency,-rt -- %command%` | Explicit profile algebra |
| `hx --auto -- %command%` | Short alias |
| `helios-ultra -- %command%` | Symlink alias (after `helios link ultra`) |

Everything after the first `--` is passed verbatim to `exec`, preserving any internal `--` tokens generated by Steam (`reaper ... -- ...`).

## Profiles

### Base profiles

| Name | Environment variables |
|---|---|
| `rt` | `VKD3D_CONFIG=dxr,dxr11`, `PROTON_HIDE_NVIDIA_GPU=0` |
| `dlss` | `PROTON_ENABLE_NVAPI=1`, `DXVK_ENABLE_NVAPI=1`, `PROTON_HIDE_NVIDIA_GPU=0` |
| `perf` | `DXVK_ASYNC=1`, `__GL_SHADER_DISK_CACHE=1`, `__GL_SHADER_DISK_CACHE_PATH=${CACHE_DIR}/gl-shader-cache` |
| `fsync` | `PROTON_NO_ESYNC=0`, `PROTON_NO_FSYNC=0` |
| `latency` | `__GL_MaxFramesAllowed=1`, `__GL_SYNC_TO_VBLANK=0` |
| `ngx` | `PROTON_ENABLE_NGX_UPDATER=1` |
| `dlss_upgrade` | `PROTON_DLSS_UPGRADE=1` |
| `gplasync` | `DXVK_GPLASYNC=1` |
| `cache_size` | `__GL_SHADER_DISK_CACHE_SIZE=10737418240` |
| `cache_skip_cleanup` | `__GL_SHADER_DISK_CACHE_SKIP_CLEANUP=1` |
| `vkd3d_cache` | `VKD3D_SHADER_CACHE_PATH=${CACHE_DIR}/vkd3d-shader-cache` |
| `vkd3d_latency` | `VKD3D_SWAPCHAIN_LATENCY_FRAMES=1` |

### Meta-profiles

| Name | Expansion |
|---|---|
| `auto` | RTX 20/30/40/50 -> `dlss,rt,perf`; GTX -> `perf`; no NVIDIA GPU -> pass-through |
| `ultra` | GPU-tiered full set (RTX 40/50: all base profiles; RTX 30: drops `ngx`/`dlss_upgrade`; RTX 20: drops `gplasync`/`vkd3d_latency`; GTX: `perf,latency`) |
| `full` | `dlss,rt,perf,fsync` |
| `comp` / `competitive` | `perf,latency` |
| `re_engine` | `dlss,rt,perf,fsync,latency,ngx,dlss_upgrade,gplasync,cache_size,cache_skip_cleanup,vkd3d_cache,vkd3d_latency` |

### Profile algebra

Profiles are comma-separated. `+` adds (default) and `-` removes a base profile after meta-profile expansion:

```bash
helios --profile=auto,-rt -- %command%
helios --auto --no-rt -- %command%
helios --full --no-fsync -- %command%
```

### Resolution priority

1. Explicit CLI flags (`--profile`, `--auto`, `--rt`, ...)
2. Symlink invocation (`helios-<name>`, `hx-<name>`, `helios_alias_<name>`)
3. Per-game override (`HELIOS_APP_<appid>`)
4. Config default (`HELIOS_DEFAULT_PROFILES`)
5. Fallback to `auto`

### Anticheat filtering

When a known competitive AppID is active (built-in list or `HELIOS_COMPETITIVE_<appid>="1"`), Helios strips profiles that alter DXVK/VKD3D/NVAPI hooks (`rt`, `dlss`, `ngx`, `dlss_upgrade`, `gplasync`, `vkd3d_cache`, `vkd3d_latency`) after meta-profile expansion, leaving cache/sync/latency settings intact. Pass `--unsafe` to disable this check.

## Subcommands

### Diagnostics & inspection

```bash
helios scan          # GPU, driver, Steam paths, active AppID, config counts
helios doctor        # alias for scan
helios modes         # profile definitions and priority order
helios diff <a> <b>  # compare env vars produced by two profile strings
```

### Per-game overrides & aliases

```bash
helios set <appid> <profiles>
helios unset <appid>
helios games

helios alias set <name> <profiles>
helios alias unset <name>
helios alias list

helios link <name> [profiles]       # creates helios-<name> symlink
helios unlink <name> [--purge]      # --purge also removes alias from config
helios links
```

### DLL management

```bash
helios dll list <dir>               # locate nvngx_dlss*.dll with size and SHA256
helios dll backup <file.dll>        # timestamped backup
helios dll swap <target> <new>      # backup target, verify MZ header, replace
helios dll restore <target>         # restore newest backup
```

### Auto-tune & config

```bash
helios autotune <appid> [--dir <path>] [--yes]
helios export [file]
helios import <file> [--merge|--replace]
```

`autotune` reads Steam's `libraryfolders.vdf` and `appmanifest_<appid>.acf`, checks for DLSS DLLs and DX12 indicators, and suggests (or writes with `--yes`) a profile override.

## Wrapper flags

- `--verbose`, `-v`: Print resolved profile, GPU tier, env vars, and command to stderr.
- `--dry-run`: Print the `env` command without running it.
- `--config <file>`: Use an alternate config file.
- `--unsafe`: Disable anticheat profile filtering.
- `helios run [flags] -- <command>`: Explicit wrapper subcommand.

## Configuration

Config path: `~/.config/helios/helios.conf` (parsed line-by-line without `source` or `eval`; values with shell metacharacters are rejected).

```ini
HELIOS_DEFAULT_PROFILES="auto"
HELIOS_APP_1091500="ultra"
HELIOS_ALIAS_no-rt="auto,-rt"
HELIOS_PROFILE_custom="DXVK_HUD=fps PROTON_ENABLE_NVAPI=1"
HELIOS_COMPETITIVE_730="1"
HELIOS_BATTERY_PROFILE="perf"
```

When `HELIOS_BATTERY_PROFILE` is set and the system is discharging on battery, `auto` and `ultra` switch to that profile on systems without a dedicated NVIDIA GPU path active.
